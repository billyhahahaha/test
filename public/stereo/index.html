Format notes & conversion recipes

MV-HEVC / Apple spatial video decodes here as its base (left) view only — browsers expose no second-view API outside an immersive context. Convert to side-by-side for cross-browser stereo.

# spatial .MOV -> full side-by-side
ffmpeg -i spatial.MOV -filter_complex \
  "[0:v:0][0:v:1]hstack=inputs=2" \
  -c:v libx264 -crf 18 -pix_fmt yuv420p sbs.mp4

# full SBS -> half SBS (same pixel budget, squeezed)
ffmpeg -i sbs.mp4 -vf "scale=iw/2:ih" -c:v libx264 -crf 18 half_sbs.mp4
